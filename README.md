# Meu Ponto — GitHub Pages

Arquivos prontos para publicação no GitHub Pages.

## Publicar
1. Crie um repositório no GitHub, por exemplo `meu-ponto`.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)** e salve.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## Instalar no Android
Abra o endereço publicado no Chrome e use o menu do navegador > **Adicionar à tela inicial** ou **Instalar app**.

Observação: os registros são armazenados localmente no navegador/aparelho. Faça backups pelo próprio aplicativo.
